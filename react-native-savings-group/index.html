React Native: Build a Savings Group App

Ten weeks, one skill per week. Each week ends with a working feature of a real app that savings groups can use instead of a paper record book.

Starting November 202610 weeks1–2 hours a dayFree
🎯
The problem

Savings groups keep records in one paper book. It can get lost, entries get disputed, and members can't check their balance.

📱
The app

Treasurers record meetings offline, and members see their savings and loans, or get them by SMS on basic phones.

🛠️
The stack

Expo + React Native + TypeScript on the phone. Next.js, Prisma, PostgreSQL and Better Auth on the server.

✅ Before you start

1. Install Node.js and VS Code
2. Install the Expo Go app on your phone
3. Know basic JavaScript and React. If not, start with React: Learn
4. Talk to a savings group and note their rules: share price, interest, fines, cycle length
